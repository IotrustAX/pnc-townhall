[발표자료 통합 상영 - 사용법]

■ 기본 사용
1. 이 폴더(발표자료_통합) 전체를 발표할 PC로 복사합니다.
   (압축해서 USB/드라이브/메일로 옮겨도 되고, 인터넷 연결은 필요 없습니다.)
2. hub.html 파일을 더블클릭해서 엽니다. (크롬 또는 엣지 권장)
3. 화면 아래 "이전 / 다음" 버튼으로 연사를 넘깁니다.
4. 오른쪽 아래 ▾ 버튼으로 컨트롤 바를 숨겼다/보였다 할 수 있습니다. (실제 발표 중엔 숨겨두세요)
5. ⛶ 버튼을 누르면 전체화면으로 전환됩니다.

■ 발표자료 추가하는 법
1. speakers 폴더 안에 연사별 파일(html 또는 pdf)을 넣습니다.
2. hub.html 파일을 메모장(또는 에디터)으로 열고, 아래 목록 부분을 수정합니다.

   const SPEAKERS = [
     { name: "연사 이름", file: "speakers/파일이름.pdf" },
     { name: "연사 이름", file: "speakers/파일이름.html" },
   ];

   - name: 화면 하단에 표시될 이름
   - file: speakers 폴더에 넣은 실제 파일명
   - 순서대로 한 줄씩 추가하면, 그 순서대로 상영됩니다.
3. 저장 후 hub.html을 새로고침하면 바로 반영됩니다.

■ PDF 자료는 어떻게 되나요?
따로 변환할 필요 없습니다. speakers 폴더에 PDF 파일을 그대로 넣고 목록에 추가하면,
브라우저가 PDF를 그대로(깨지지 않게) 보여줍니다. 화살표 키나 마우스로 페이지를 넘길 수 있습니다.

■ 주의사항
- "이전/다음" 버튼은 연사를 바꿀 때만 쓰고, 그 연사 자료 안에서 페이지(슬라이드)를 넘기는 건
  해당 자료 화면을 직접 클릭한 뒤 방향키/스페이스바 등을 쓰면 됩니다.
- 발표 PC에는 크롬 또는 엣지 브라우저가 설치되어 있어야 합니다. (대부분의 PC에 기본 설치됨)
