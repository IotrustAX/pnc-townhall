[타운홀 발표자료 통합 상영 - 사용법]

■ 발표 당일 (제일 중요)
1. 발표 PC 브라우저(크롬 권장)에서 접속: https://pnc-townhall.recruit-9d6.workers.dev
2. 로그인 화면이 뜨면 "Email" 칸에 office@iotrust.kr (또는 본인 iotrust.kr 메일) 입력 → "Send login code"
3. 그 메일함에서 받은 6자리 코드 입력 → 통과하면 발표자료 목록 뜸
4. 이번 달 회차 클릭 → 상영 화면 진입
5. 화면 아래 "이전 연사 / 다음 연사"로 연사 넘기기, 가운데 이름을 누르면 전체 연사 목록에서 바로 이동, ⛶로 전체화면
6. 컨트롤 바는 평소엔 숨겨져 있다가, 마우스를 화면 아래쪽으로 가져가면 보이고 벗어나면 다시 숨습니다.

이 링크는 iotrust.kr 메일 가진 사람만 로그인해서 볼 수 있습니다 (Cloudflare Access 설정, recruit@iotrust.kr 계정 소유).

■ 다음 달 발표자료로 갱신하려면
Claude(저)한테 다음 달 발표자료 파일(PDF/HTML)과 연사 이름을 전달해주세요.
제가 새 회차 폴더를 만들어서 깃허브에 올리면, 1~2분 안에 자동으로 사이트에 반영됩니다.
지난 달 회차 링크도 계속 남아있어서 나중에 다시 볼 수 있습니다.

■ (백업용) 인터넷 없이 로컬에서 여는 법
이 폴더(발표자료_통합) 전체를 복사해서 다른 PC에 옮긴 뒤, events/해당월/hub.html을 더블클릭해도
똑같이 동작합니다. 인터넷 연결이 끊기거나 사이트 접속이 안 될 때 비상용으로 쓰세요.

■ 발표자료 넣는 법 (저한테 맡기지 않고 직접 하고 싶을 때)
1. events/2026-11/speakers 처럼, 해당 월 폴더 안 speakers 폴더에 연사별 파일(html 또는 pdf)을 넣습니다.
2. 같은 폴더의 hub.html을 메모장으로 열고, 아래 목록을 수정합니다.

   const SPEAKERS = [
     { name: "연사 이름", file: "speakers/파일이름.pdf" },
     { name: "연사 이름", file: "speakers/파일이름.html" },
   ];

3. 저장 후 깃허브에 올리면(push) 자동 반영됩니다. (이 부분은 어려우면 그냥 저한테 파일만 주세요)

■ PDF는 변환 필요 없음
speakers 폴더에 PDF를 그대로 넣으면 브라우저 자체 뷰어로 깨지지 않고 보여줍니다.

■ 지난 발표자료 삭제하고 싶을 때
"이번 달(또는 OO월) 거 지워줘"라고 요청하시면 제가 다음을 처리합니다:
1. events/해당월 폴더 전체 삭제 (발표자료 파일 포함)
2. index.html에서 그 회차로 가는 링크 제거
3. 커밋 후 깃허브에 push → 사이트에서 즉시 사라짐
※ 단, 깃 커밋 기록(히스토리) 자체에서 완전히 지우는 것까지는 하지 않습니다(그렇게 하려면 강제 재작성
  작업이 추가로 필요). 지금 수준(최신 상태에서 안 보이게)으로 충분하다고 판단해서 이렇게 운영하기로
  했습니다. 혹시 완전 삭제가 필요해지면 그때 따로 말씀해주세요.

■ 주의사항
- "이전 연사/다음 연사" 버튼은 연사를 바꿀 때만 쓰고, 한 연사 자료 안의 페이지 넘김은 방향키/스페이스바로 합니다.
- PDF 자료는 마우스 클릭으로도 페이지를 넘길 수 있습니다: 화면 오른쪽 클릭 = 다음 페이지, 왼쪽 클릭 = 이전 페이지.
- 로그인 코드가 스팸함으로 갈 수 있으니, 안 오면 스팸함도 확인하세요.
